Welcome to your new book! This is a sample chapter generated by **Booksmith**.

Booksmith converts Markdown chapters into beautifully formatted PDF and EPUB publications using Prawn, GEPUB, and Kramdown.

## Features Overview

Booksmith provides a rich set of layout and typography enhancements:

- **Configurable typography**: Fonts, sizes, and leading customizable via `config/book.yml`
- **Subtitle comments**: Add subtitles right under chapter titles without breaking Markdown linters
- **Specialized callouts**: Standard, alternate, and exercise blockquotes
- **Smart page breaks**: Invisible page break markers for precise print layout

### Callouts and Blockquotes

Booksmith supports three distinct blockquote styles.

> **Standard Callout**
>
> When the first line is wrapped in bold text, Booksmith renders it as a distinct header row inside the shaded callout box.

> **Alternate Callout**
>
> Use `{: .alt_blockquote}` for secondary notes, sidebars, or slightly different background tinting.
{: .alt_blockquote}

> Try It Yourself
>
> Exercise callouts feature an icon (configured in `config/book.yml`) and are styled for hands-on activities:
>
> - What is the main thesis of your book?
> - Who is the intended reader?
{: .exercise_blockquote}
